# HTML-AND-CSS-PROJECTS
This is a repository for HTML and CSS projects

This repository showcases the projects I completed while learning front-end web development through The Tech Academy. Throughout these projects, I focused on creating responsive layouts, improving accessibility, debugging code, and developing a better understanding of modern web design principles. Every project helped strengthen my problem-solving skills and gave me hands-on experience with real web development concepts.

## Featured Projects

### About My Cat

Two HTML files that introduced the fundamentals of HTML. This project includes page navigation, images, embedded YouTube videos, and semantic HTML elements.

### Basic HTML and JavaScript

A collection of exercises that strengthened my understanding of HTML structure and introduced basic JavaScript concepts. The project emphasizes accessibility, proper formatting, and organized page layouts.

### Basic HTML and CSS

A series of webpages demonstrating how CSS enhances the appearance of HTML documents. Through these exercises, I practiced styling text, lists, typography, and page layouts while learning how to separate content from presentation.

### The Pet Shop Website

A beginner-friendly website created while following a guided tutorial. I expanded the original project by adding accessibility improvements, meta descriptions, and semantic HTML elements to create a more complete and user-friendly website.

### Explore the Ancient Sites of Belize

A one-page website featuring internal navigation, image galleries, embedded videos, a contact form, and a footer. This project demonstrates my ability to organize content effectively within a single-page layout while creating a smooth user experience.

### CSS Effects

A project focused on improving the visual design of a webpage through custom typography and interactive hover effects. Working with Google Fonts and CSS transformations helped me better understand how styling enhances usability and presentation.

### Simple Recipes

A responsive HTML and CSS website based on a tutorial series. I personalized the project by adding an original About section and refining the layout to create a more complete website.

### Code Errors Challenge

A debugging exercise where I identified and corrected multiple HTML and CSS errors, including broken links, incorrect syntax, styling issues, image formatting, and embedded media. This project strengthened my troubleshooting skills and attention to detail.

### Belize Website CSS Upgrade

An enhanced version of my Belize website where I applied external CSS styling to improve typography, forms, spacing, borders, and the overall appearance of the site.

### Academy Cinemas

A responsive movie theater website built with Bootstrap. This project allowed me to work with Bootstrap components, responsive layouts, navigation, cards, and custom page sections while gaining experience using a popular front-end framework.

### HTML & CSS Challenges

A collection of coding challenges completed throughout the course that reinforced concepts such as semantic HTML, CSS styling, responsive layouts, accessibility, and clean coding practices.
